🔒 Yours, and only yours

No server, no account, no sign-up. Your records live in this browser and you decide when and where a backup goes. When you use an AI feature, the relevant text is sent straight from your browser to Groq using your own API key. Nothing passes through us.

Install it

Works in any modern browser, and installs like an app. It keeps working offline once it has loaded.

iPhone / iPad

Open the app in Safari, tap Share, then Add to Home Screen.

Android

Open the app in Chrome, tap the menu, then Install app.

Desktop

In Chrome or Edge, click the install icon in the address bar.
